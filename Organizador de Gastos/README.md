# Organizador de Gastos

Projeto desenvolvido em Python para registrar e analisar gastos pessoais.

## Funcionalidades

- Cadastro de gastos
- Classificação por categoria
- Cálculo do total gasto
- Cálculo da média dos gastos
- Identificação do maior gasto
- Identificação do menor gasto
- Análise dos gastos por categoria

## Tecnologias

- Python
